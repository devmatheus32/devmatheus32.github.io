Sobre mim

Opa, eai! Sou o Matheus Nascimento, desenvolvedor backend desde 2023. Gosto de transformar ideias em software, criando APIs, aplicações desktop e aplicações web.

Meu foco é desenvolver, corrigir e planejar sistemas de forma rápida, estável e escalável, sempre buscando escrever código limpo e de fácil manutenção. Minha linguagem favorita é o Java.

Ao longo dos meus projetos, fui aprendendo com os erros e melhorando cada vez mais. Cada projeto me ajudou a evoluir em lógica de programação, análise e entendimento de problemas, arquitetura, desenvolvimento de APIs e integração com bancos de dados.
